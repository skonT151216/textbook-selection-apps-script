여기서 시작하세요

설치는 업무담당자가 한 번만 합니다. 선생님은 담당자가 알려 준 웹 주소에서 본인 아이디로 접속하면 됩니다.

이 파일은 설치 안내입니다.
프로그램은 Index.html을 컴퓨터에서 더블클릭해서 실행하는 방식이 아닙니다. 아래 순서대로 Google에 설치한 뒤 웹 앱 주소를 엽니다.

담당자: 최초 설치 6단계

1
압축파일을 풀고 빈 스프레드시트를 만듭니다.
학교별로 별도 파일을 만들고, 확장 프로그램 → Apps Script를 엽니다.
2
프로그램 파일 3개를 복사합니다.
파일은 메모장 등으로 열어 전체 내용을 복사하고, 구글 편집기에서도 기존 내용을 전부 선택한 뒤 교체합니다.
받은 파일Google 편집기에서 넣을 곳
Code.gs기본 Code.gs 전체 교체
Index.html+ → HTML → 이름을 Index로 생성 후 전체 교체
appsscript.json프로젝트 설정에서 매니페스트 표시 후 전체 교체
Index 안의 긴 영문·숫자는 정상입니다. 내용을 수정하거나 일부만 복사하지 마세요. 저장 완료 표시를 기다립니다.
3
파일이 제대로 복사되었는지 확인합니다.
Code.gs 선택 → 함수 verifyInstallation 선택 → 실행. 로그에 "complete":true, "error":""가 나오는지 확인합니다.
4
학교와 최초 담당자 아이디를 설정합니다.
스프레드시트로 돌아가 새로고침 → 교과서 선정 프로그램 → 최초 학교 설정. 학교명과 담당자 아이디를 입력합니다. 최초 권한 승인은 담당자 계정에서 진행합니다. 생성되는 _APP_DATA 시트는 지우거나 직접 수정하지 마세요.
5
웹 앱으로 배포합니다.
Apps Script → 배포 → 새 배포 → 웹 앱. 실행 사용자 나, 접근 권한 모든 사용자로 배포하고 /exec로 끝나는 주소를 복사합니다.
조직 정책으로 모든 사용자가 허용되지 않으면 학교 Google 관리자와 확인해야 합니다. 공식 절차: Google 웹 앱 배포 안내.
6
담당자 로그인 → 학교 업무 설정 → 테스트합니다.
도서, 교직원 아이디, 교과협의회와 역할을 저장합니다. 가상 자료로 저장 후 새로고침, 서식 테스트의 PDF 4쪽과 다운로드를 확인한 뒤 선생님께 안내합니다.
아이디가 곧 접근 수단입니다.
아이디를 아는 사람은 해당 계정으로 접속할 수 있습니다. 추측하기 어려운 아이디를 개별 발급하고 주소·아이디 목록은 학교 밖에 공유하지 마세요. 학생 개인정보 등 민감한 자료는 입력하지 않습니다.

선생님: 접속부터 저장까지

  1. 담당자가 보낸 웹 앱 주소를 엽니다.
  2. 본인 학교 아이디 → 내 업무 시작하기.
  3. 이름·교과 확인 후 화면 순서대로 평가를 작성합니다. 역할별 자세한 안내는 앱의 사용 매뉴얼에 있습니다.
  4. 저장 완료 표시를 확인한 뒤 작업을 마치고 로그아웃합니다.

일반 선생님은 Apps Script 편집기를 열거나 프로그램을 설치할 필요가 없습니다.

개인평가표 2장 + 총괄표 1장 + 추천의견서 1장입니다. 가상 이름·점수·의견·TEST 서명을 사용했으며 제출용이 아닙니다.

앱에서는 담당자가 서식 테스트 → 서식1·2·3 예시 자동 생성 → 선택한 예시 PDF 미리보기를 누릅니다. 끝까지 내려 모든 페이지를 확인하고 PDF 다운로드를 누릅니다.

기존 설치를 업데이트할 때

같은 압축본의 Code.gs와 Index.html을 함께 교체하고 저장합니다. 배포 → 배포 관리 → 수정 → 새 버전 → 배포로 업데이트합니다. 기존 학교 설정과 데이터는 그대로 둡니다. Google 배포 관리 안내
