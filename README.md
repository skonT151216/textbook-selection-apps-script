# 교과용도서 선정 프로그램

**평가 작성부터 서식 1·2·3 PDF 출력까지, 학교별로 설치해 사용하는 프로그램입니다.**

학교 담당자가 Google Apps Script와 스프레드시트에 설치하고, 선생님에게 학교 아이디를 발급합니다. 일반 선생님은 별도 프로그램 설치 없이 웹 앱 주소에서 본인 아이디로 접속합니다.

## 먼저 다운로드하세요

### [최신 설치용 ZIP 다운로드 →](https://github.com/skonT151216/textbook-selection-apps-script/releases/latest)

위 페이지의 Assets에서 `textbook-selection-gas-20260919-r5.zip` 파일을 받으세요. GitHub가 자동 제공하는 `Source code (zip)`이 아니라 **첨부된 설치용 ZIP**입니다.

### 2026-09-19 수정 배포 안내

r5에서는 개인별 평가 PDF의 과목·위원·서명을 표 위에 배치해, 도서가 많아도 서명이 (인) 위에 보이도록 수정했습니다. 평가내용 작성용 서식에는 서명을 표시하지 않습니다. 가상 도서 10종과 TEST 서명으로 PDF를 확인했습니다.


r3에서는 최초 설정의 **교직원 파일 일괄 등록**을 고쳤습니다. 새 학교의 협의회 명단이 비어 있어도 `이름 / 교과 / 계정` 파일을 올리면 해당 교과 교사를 한 번에 등록하고 협의회에 연결합니다. 등록하지 않은 교과의 직원은 제외하며, 이미 등록된 교사는 아이디만 갱신합니다. 적용 후 교과부장·서식2 작성자를 지정하고 마지막 단계에서 **설정 저장**을 눌러야 반영됩니다.

이전 배포본의 최초 설정 기본값에 특정 학교의 교직원 명단과 역할이 포함되는 문제가 있었습니다. 이번 수정본은 **교직원·역할·도서·평가·추천의견이 빈 상태**로 시작합니다. 이전 ZIP은 새 설치에 사용하지 마세요.

이미 설치했다면 스프레드시트를 먼저 백업하고, 이번 ZIP의 Code.gs와 Index.html 전체를 각각 교체·저장한 뒤 **배포 → 배포 관리 → 수정 → 새 버전 → 배포**를 선택하세요. 기존 initializeSchool을 다시 실행하거나 데이터 시트를 삭제할 필요는 없습니다.

최초 설정을 저장하지 않았다면 업데이트된 웹 앱을 새로고침해 확인하세요. 이미 저장한 명단은 학교 운영 데이터이므로 자동 삭제하지 않습니다. 남아 있는 명단은 담당자가 확인 후 수정해야 합니다. 과거 Git 기록, 이전 다운로드 및 제3자 사본은 최신 배포 교체만으로 제거되지 않습니다.

1. ZIP 압축을 풉니다.
2. `처음_시작하기.html` 파일을 더블클릭해 설치 순서를 확인합니다.
3. Google Apps Script에 `Code.gs`, `Index.html`, `appsscript.json` 세 파일을 넣습니다.
4. 학교 최초 설정과 웹 앱 배포를 마친 뒤, 각 선생님에게 웹 앱 주소와 본인 아이디를 개별 안내합니다.

> GitHub 링크는 프로그램을 받는 곳입니다. 링크를 누르는 것만으로 업무 프로그램이 실행되지는 않습니다. 각 학교 담당자의 최초 설치가 필요하며, 이후 선생님들은 해당 학교의 웹 앱에 접속합니다.

## 어떤 일을 할 수 있나요?

- 학교·도서·교과협의회 및 교직원 역할 설정
- 담당자가 발급한 학교 아이디로 접속
- 평가기준, 개인별 순위·점수·의견 작성과 저장
- 총괄표와 추천의견서 작성
- 서식 1·2·3 개별·묶음 PDF 미리보기 및 다운로드
- 실제 평가자료와 분리된 가상 서식 테스트
- 역할별 사용 매뉴얼

## 검증한 내용

r5는 자동 테스트 92개와 웹·Apps Script 빌드를 통과했습니다. 가상 학교·교사·도서 10종·평가기준 8개로 4쪽 PDF를 만들고, 개인평가표의 TEST 서명이 (인) 위에 보이는 것을 실제 PDF 렌더링으로 확인했습니다. 앞선 버전에서는 실제 Google Apps Script 환경의 저장과 PDF 출력도 검증했지만, r5 자체를 학교 운영 웹 앱에 재배포해 확인한 것은 아닙니다.

이는 모든 학교 정책·브라우저·입력 자료나 대규모 동시 접속을 보장한다는 뜻은 아닙니다. 학교별로 소규모 자료를 먼저 테스트하고, 실제 제출 전 서식·수치·서명을 확인하세요.

## 운영할 때 꼭 확인하세요

- **아이디 자체가 접근 수단입니다.** 아이디를 아는 사람은 그 계정으로 접속할 수 있습니다. 추측하기 어려운 값을 발급하고 개별 안내하세요.
- 웹 앱 주소·아이디 목록·평가자료·실제 서명은 공개하지 마세요. 학생 개인정보 등 민감한 자료를 입력하지 않습니다.
- Google 로그인을 요구하지 않는 교사 접속은 설치 시 익명 접근이 허용되어야 합니다. 학교 Google Workspace 정책에 따라 제한될 수 있습니다.
- 각 학교는 별도의 스프레드시트와 Apps Script에 설치합니다. 최신 설치 파일에는 학교 운영 명단을 기본값으로 넣지 않습니다. 이전 공개 기록에는 과거 버전이 남을 수 있습니다.
- 업데이트할 때는 같은 배포본의 Code.gs·Index.html을 함께 교체하고 **배포 관리 → 새 버전**을 반영합니다. 기존 데이터 시트는 삭제하지 않습니다.
